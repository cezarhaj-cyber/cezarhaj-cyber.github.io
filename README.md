# Mihai Cezar Hâj — CV

Bilingual (English / Română) web CV, published with GitHub Pages.

- `index.html` is the page itself: one self-contained file.
- Switch the language with the EN/RO buttons, or link to a specific language with `?lang=en` / `?lang=ro`.
- **Print / PDF** prints the language currently on screen.
- `src/cv_data.py` holds all the content and `src/build.py` regenerates the page (`python3 src/build.py index.html`).

Source: Europass CV (RO), July 2026, updated November 2026.
